# PPSC MasterPrep & Question Bank Exam Portal

An all-in-one exam simulation and comprehensive question bank web application built for Punjab Public Service Commission (PPSC) competitive exams (PMS, Tehsildar, Sub-Inspector, Assistant S&GAD, Junior Clerk, Educators, and one-paper tests).

---

## 🌟 Key Features

- **3,600+ Authentic Solved MCQs**: 400 verified MCQs for every one of the 9 official PPSC subjects with detailed explanations.
- **245 Solved Past Papers Archive (2019–2026)**: Searchable directory by Department, Year, and BPS Grade with 1-click test launch.
- **Full 100-MCQ Mock Exam Simulator**: 90-minute countdown timer with official PPSC $-0.25$ negative marking simulation and color-coded question palette.
- **Dynamic Question & Option Shuffling**: Every test session randomly samples and mixes questions and answers so students can practice continuously.
- **Targeted Subject Practice**: Instant feedback learn mode or timed quiz mode for any subject.
- **Interactive 3D Flashcards**: Flip cards for rapid revision.
- **Mistake Book & Weak Points**: Automatically logs incorrect answers for targeted re-testing.
- **Data Export**: 1-click download of the dataset as JSON or CSV.
